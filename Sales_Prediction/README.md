# 📊 Sales Prediction 

This project predicts product sales based on advertising budgets using a Linear Regression model. The model is trained on advertising data containing TV, Radio, and Newspaper marketing expenditures and their corresponding sales figures.

##  Features

* Predict sales using advertising budgets
* Interactive Streamlit web application
* Data visualization and correlation analysis
* Machine Learning model built using Linear Regression
* Simple and user-friendly interface

##  Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn
* Streamlit
* Pickle

##  Dataset

The dataset contains:

* TV advertising budget
* Radio advertising budget
* Newspaper advertising budget
* Sales

##  Model Performance

* Mean Absolute Error (MAE): 1.27
* Mean Squared Error (MSE): 2.91
* R² Score: 0.91

The model achieved a strong R² score, indicating that it explains most of the variation in sales based on advertising expenditure.

##  Application Preview

Users can:

1. Enter TV advertising budget
2. Enter Radio advertising budget
3. Enter Newspaper advertising budget
4. Click the Predict Sales button
5. View the predicted sales value instantly

##  How to Run

Clone the repository:

```bash
git clone <repository-link>
```

Install required libraries:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
